# Lab 2.2: Interactive Features and Testing

In this final lab you will add interactive features and explore automated testing with Playwright MCP.

## Setup

Install the Playwright MCP server for your AI tool. For Claude Code: `claude mcp add playwright`

## Tasks

1. Add a contact form with validation to your landing page
2. Implement hover animations and transitions using CSS
3. Configure Playwright MCP and connect it to your AI tool
4. Use your AI tool with Playwright to open your landing page at `localhost:8000`
5. Ask the AI to take a screenshot of your site using Playwright
6. Use the screenshot to iterate and refine your design further

By the end of this lab you should have a complete, interactive personal landing page. You've learned how to combine multi-modal programming with automated testing tools to build and refine websites efficiently.

Explore additional features like dark mode, animations, or deployment to make your landing page production-ready.
