# Lab 1.3: Building Your Landing Page Foundation

In this lab you will start building your professional personal landing page using multi-modal programming techniques.

## Setup

Create your landing page project structure with `index.html`, `css/` and `js/` folders. Set up Live Server in VS Code.

## Tasks

1. Gather visual inspiration from sites like [One Page Love](https://onepagelove.com/) - screenshot specific components only
2. Use your AI tool to generate semantic HTML5 structure for a landing page (nav, hero, about, contact sections)
3. Build a responsive navigation bar using a screenshot reference and detailed prompt
4. Create a hero section with your professional headline and call-to-action button
5. Test responsiveness using browser DevTools at 320px, 768px, and 1920px widths
6. Add smooth scrolling navigation with JavaScript

By the end of this lab you should have a working landing page foundation with navigation and hero section. Use browser DevTools to inspect and debug your layout as you build.
