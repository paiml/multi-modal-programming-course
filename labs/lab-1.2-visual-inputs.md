# Lab 1.2: Visual Input and Prompt Engineering

In this lab you will practice effective prompt engineering with visual inputs to get better code results.

## Setup

Have your AI tool ready and create a new practice project folder.

## Tasks

1. Take a full-page website screenshot and ask AI to "build this website" - observe the large amount of generated code
2. Take a screenshot of ONLY a single component (nav bar, button, or card) and generate code for just that element
3. Practice writing detailed prompts that combine screenshots with specific requirements (responsive, accessible, frameworks)
4. Experiment with GitHub Copilot's Agent Mode vs Ask Mode
5. Screenshot a complex UI element and break it down into smaller components

By the end of this lab you should understand that **specific screenshots produce better results** than generic full-page screenshots. Focus on the smallest component possible when iterating.
