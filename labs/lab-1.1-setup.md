# Lab 1.1: Setting Up Multi-modal Development Tools

In this lab you will install an AI development tool with visual input capabilities.

## Setup

Choose and install one of the following tools:
- [Claude Code](https://www.anthropic.com/claude-code) (requires Claude Pro subscription)
- [Gemini CLI](https://github.com/google-gemini/gemini-cli) (free tier available)
- [GitHub Copilot](https://github.com/features/copilot) (free for students/open source)

## Tasks

1. Install your chosen AI tool and configure API keys if needed
2. Create a test project directory and initialize Git
3. Test the tool by submitting a simple screenshot with a prompt
4. Verify the tool can generate HTML/CSS from visual inputs
5. Set up VS Code with Live Server extension

By the end of this lab you should be able to provide screenshots to your AI tool and receive code suggestions. You are ready to explore prompt engineering techniques in the next lab.
