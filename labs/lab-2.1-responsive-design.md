# Lab 2.1: Advanced Layouts and Responsive Design

In this lab you will refine your landing page with documentation-driven design and iterative improvements using screenshots.

## Setup

Open your landing page project from Lab 1.3 in your development environment.

## Tasks

1. Create a `DESIGN.md` documentation file defining your design constraints (colors, typography, responsiveness, frameworks to avoid)
2. Use this documentation in your AI prompts to ensure consistency across iterations
3. Build the About and Skills sections using component-specific screenshots
4. Take a screenshot of your current progress and ask AI to make the typography bolder and more impactful
5. Iterate on font choices and spacing - make changes, screenshot, refine
6. Set up basic HTML/CSS validation checks

By the end of this lab you should understand how documentation helps maintain consistency when iterating. Your landing page should have multiple sections with refined typography and responsive layouts.
